AutoTestAI

LLM-powered automated test generation

Jan 2026 – May 2026

  • Python
  • LLM
  • Groq
  • Program analysis

Given a Python project and a functional specification, AutoTestAI parses the codebase, associates each function with its spec using an LLM, and generates meaningful unit tests automatically.

Key design decisions

  • Spec-driven test generation rather than purely syntactic coverage
  • LLM-based function-to-spec association with confidence scoring
  • Powered by Groq's free inference tier (14,400 requests per day)
  • Modular pipeline — parse, associate, generate — with optional mutation and path analysis

This project sits at the intersection of program analysis and LLM reasoning, an area I find increasingly relevant as the research community explores AI-assisted software engineering. It is still early, but the pipeline runs end to end. I am happy to discuss the design, its limitations, or ideas for where it could go next.

DebateArena

AI-powered debate practice platform

Jan 2026 – Apr 2026

  • React
  • Vite
  • Flask
  • Python
  • SQLite

A full-stack web application for practising structured debate against an AI opponent in real time. Users pick a topic, choose a side — for or against — and argue through five rounds. Every argument is scored from 0 to 100 on logic, evidence quality, and rebuttal strength.

Features

  • Real-time AI opponent with topic-aware arguments across 16 curated topics spanning technology, ethics, politics, education, and the environment
  • Scoring engine with logical fallacy detection and personalised post-debate coaching
  • Analytics dashboard with score trend charts, skill radar breakdowns, and full debate history
  • Authentication with JWT tokens, bcrypt password hashing, rate limiting, and parameterised SQL queries

Technical notes

  • Clean client/server separation: a React single-page app built with Vite on the front end, a Flask REST API using Blueprint routing on the back
  • Worked through a set of Windows-specific deployment problems — SQLAlchemy session management, Vite proxy failures, and socket permission errors
  • Dropped the ORM in favour of raw sqlite3 for reliability, resolving absolute paths to eliminate database binding issues
  • Integrated the AI through direct REST calls, which removed SDK version conflicts

Built as the final project for CIS 470 / CIS 602-1, Web Software Development.
